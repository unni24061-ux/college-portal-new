# 🎓 College Management System (CMS) — Phase 1

A modern, Django-powered web portal designed to streamline academic administration, user access, and core campus workflows. 

---

## 📌 Phase 1 Scope & Status

This repository currently contains **Phase 1** of the system setup. The foundational database architecture, authentication system, and core app structures are fully initialized.

### What’s Included in Phase 1:
- 🔐 **Custom Authentication & Role-Based Access (RBAC):** Custom user models supporting Admin, Teacher, and Student roles.
- 🏗️ **Core Django Apps & Structure:** Modular setup including `accounts`, `faculty`, `students`, `collegePortal`, and shared templates.
- 🗄️ **Database Schema Foundation:** Initialized structure ready to support APJKTU-style academic workflows (Departments, Courses, Profiles, Subjects, and Grades).

---

## 🚀 Future Phases (Roadmap Preview)

The underlying database schema and architecture are pre-built to support the following upcoming features in subsequent releases:

* **⚡ Dynamic QR Attendance:** Time-bound, auto-refreshing QR codes generated by teachers for instant student check-ins.
* **🤖 Local AI Poster & Merit Generator:** Privacy-first, local LLM integration (via Ollama) to automatically calculate top performers and render custom congratulatory posters.
* **📊 Interactive Analytics Dashboards:** Chart.js integration for tracking GPA distributions, attendance thresholds, and semester growth trends.
* **📜 Digital Merit Badges & Certificates:** Verified award generation equipped with tamper-proof QR verification links.

---

## 🛠️ Tech Stack (Phase 1 Setup)

* **Backend:** Django 5.x (Python 3.11+)
* **Database:** SQLite3 (Development) / PostgreSQL (Production ready)
* **Frontend:** Django HTML Templates, Tailwind CSS / Bootstrap 5
